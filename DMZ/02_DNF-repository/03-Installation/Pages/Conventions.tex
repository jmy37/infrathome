\subsection{Convention d'écriture pour la suivte du document}
Dans la suite de ce document, les éléments suivants seront appliqués, et sont à adapter à l'environnement de destination:
\begin{itemize}
    \item Le compte de service sera \texttt{svc\_repodnf}
    \item La base du service web sera \texttt{/var/www/html}
    \item Le répertoire de configuration du script de téléchargement sera \texttt{/opt/sync\_sources}
    \item Le script de récupération des sources sera \texttt{sync\_sources.sh}
\end{itemize}
